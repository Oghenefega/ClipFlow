The one decision I need from you

TikTok, Instagram and Facebook captions are one template each, shared by every game. Only YouTube is stored per game. So when the panel says "Rocket League", those three aren't actually Rocket League's — they're everyone's.

Option A — leave them global (my recommendation). The panel labels them GLOBAL · ALL GAMES so nothing is pretending. You keep 3 templates instead of 9, and #{gametitle} already swaps the hashtag per clip, so a Rocket League post and an ARC Raiders post already come out different. Nothing in storage changes, nothing can break on old clips. This is a labelling job.

Option B — make them per-game with a global fallback. Every game can override any of the three; unset ones stay marked GLOBAL and fall through. More power, but it's a storage change (new shape under caption templates + a migration), it touches the publish path, and it turns 3 templates you maintain into up to 12. It also overlaps #290/#287/#291, which are their own untangling.

I'd ship A this session and file B as its own issue if you ever hit a game that genuinely needs a different TikTok caption. Say "B" and I'll build B instead — it's roughly one extra session, not one extra hour.
